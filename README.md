# 🍰 Doughvia — Modern Bakery Website

A modern and responsive bakery website built with **React.js**, designed to provide a warm, elegant, and user-friendly experience across desktop, tablet, and mobile devices.
Doughvia focuses on clean UI, responsive layouts, reusable React components, smooth navigation, and a premium bakery-inspired visual experience.

## 📸 About The Project

**Doughvia** is a frontend bakery website created as a React.js project.

The website presents a bakery brand through different sections such as the hero section, bakery highlights, best-selling products, special celebrations, contact form, and footer.

The main goal of this project was to practice and improve:

* React component-based development
* React Router
* Responsive web design
* CSS layout and styling
* Reusable UI components
* Image-based layouts
* Git and GitHub
* GitHub Pages deployment

## 🚀 Getting Started

Follow these steps to run Doughvia locally.

### 1. Clone the repository

```bash
git clone https://github.com/Pranab0104/Doughvia.git
```

### 2. Open the project

```bash
cd Doughvia
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The project will then be available on the local development server provided by Vite.

---

## 🏗️ Build The Project

To create the production build:

```bash
npm run build
```

The production files will be generated inside the:

```text
dist/
```

folder.

---

## 🌍 Deployment

Doughvia is deployed using **GitHub Pages**.

The project uses Vite with a GitHub Pages base path:

```js
base: "/Doughvia/"
```

The deployment workflow is located at:

```text
.github/workflows/deploy.yml
```

Every time the project is updated and pushed to GitHub, the deployment workflow can build and deploy the latest version.
